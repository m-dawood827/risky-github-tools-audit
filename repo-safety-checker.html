😰 Maine pehle hi chala liya hai — ab kya karun? (I already ran it)
  1. Us computer ka internet band kar dein.
  2. Doosre saaf device se Discord ka password badlein, sab sessions se logout karein, 2FA backup codes naye banayein.
  3. Browser mein save sab passwords badlein — pehle email, banking, GitHub.
  4. Google / GitHub / Discord par connected apps aur active sessions revoke karein.
  5. API keys aur access tokens naye banayein.
  6. Crypto: naya wallet naye seed phrase se banayein aur funds transfer karein. Purana seed compromised samjhein.
  7. Antivirus / Windows Defender dobara on karein aur full scan chalayein.
  8. Startup entries aur scheduled tasks check karein.
  9. Sab se safe: sirf documents ka backup lein (koi .exe nahi), phir Windows dobara install karein.
  10. Jin logon ka data us machine par tha, un ko bata dein.
🧪 Agar test karna zaroori ho (safe lab in 6 steps)
  1. VirtualBox / VMware / Hyper-V mein aik throwaway VM banayein.
  2. Chalane se pehle har baar snapshot lein. Yehi sab se aham habit hai.
  3. VM ka network "host-only" ya bilkul off rakhein.
  4. Shared folder, clipboard sharing, drag-and-drop band rakhein.
  5. VM ke andar koi asli account login na karein — na Discord, na browser sync, na wallet, na SSH key.
  6. Kaam ke baad snapshot revert karein. Gandi VM dobara istemal na karein.
❓ Ye tool kya dekhta hai? (how it decides)

Ye tool repo ki file list, file sizes aur README parhta hai aur 8 khatray ke nishan talash karta hai: packed binary (.exe/.rar/.zip), source code ka na hona, bahri download link (MediaFire/Mega/Telegram), chalte waqt code download karna, committed secrets (token.txt/.env), self-update (version.txt), install scripts, aur hardcoded webhook/bot token.

It reads only public metadata via the GitHub API — the file tree, file sizes, and README text. It never downloads, extracts, or runs anything. A green result means the code is unlikely to attack you; it does not mean the tool is legal to use on someone else.

Defensive & educational use only. Kisi doosre ke system par bina likhi hui ijazat kuch bhi chalana jurm hai (Pakistan: PECA 2016).
No data leaves your browser except a public read-only request to api.github.com.
